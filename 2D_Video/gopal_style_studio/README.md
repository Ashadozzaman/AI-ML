# Gopal-style 2D folk-tale cartoon · JupyterLab project

A complete, working project that turns a **script (story.json)** into a ~2 minute 2D cut-out
animation video, entirely with Python. It includes an original story,
"চতুর চাঁদু ও সোনালি আম" (The Clever Jester and the Golden Mango), with three **original** characters:
a king (রাজা), a scheming minister (মন্ত্রী) and a clever jester (চাঁদু).

Runs on a normal laptop - **no GPU needed**. A full render takes about 1-2 minutes.

## 1. Install (once)

```bash
# 1) ffmpeg must be installed and on PATH   (Ubuntu: sudo apt install ffmpeg | macOS: brew install ffmpeg)
# 2) Python packages
pip install -r requirements.txt
# 3) start JupyterLab inside this folder
jupyter lab
```

## 2. Run the three notebooks in order

| notebook | what it does |
|---|---|
| `01_characters_and_backgrounds.ipynb` | checks your setup, shows the characters, rebuilds `assets/` |
| `02_voices.ipynb` | makes one voice file per line in `audio/` (edge-tts, needs internet; falls back to offline *draft* voices) |
| `03_render_video.ipynb` | preview frames, short test render, full video -> `output/gopal_style.mp4` |

`output/gopal_style_draft_voice.mp4` is a ready-made preview that uses the offline draft (humming) voice,
so you can see the animation before you create the real voices.

## 3. How it works

```
story.json  (beats: scene / say / act / enter ...)
   |
   +--> engine/timeline.py   compiles beats into tracks, reads the audio length of each line
   +--> engine/anim.py       decides the pose every frame: idle breathing, walking, talking gestures, actions
   +--> engine/rig.py        paper cut-out puppet: rotates head / torso / arms / legs around joints
   +--> engine/art.py        draws all parts, faces, props and backgrounds with Pillow
   +--> engine/audio.py      voices (edge-tts), loudness -> mouth shape (lip sync), draft voices
   +--> engine/text.py       Bangla captions
   +--> engine/render.py     camera, captions, fades, sends frames to ffmpeg
```

* **Lip sync:** the loudness of each audio frame picks the mouth shape (closed / small / mid / open / wide).
* **Walking:** legs swing and the body bobs according to how far the character moved on screen.
* **Gestures:** while talking, characters pick gestures (open hands, hand on chest, pointing...) on a repeatable random schedule.
* **Camera:** a gentle push-in toward whoever speaks. Scene changes use fades.

## 4. Make your own story

Edit `story.json` (see the table at the bottom of notebook 03). The most useful parts:

```json
{"do": "say", "who": "raja", "text": "...", "emotion": "angry", "gesture": "point", "to": "chandu",
 "also": {"mantri": "nervous"}}
```

* `emotion`: neutral happy confident angry scared nervous surprised sad thinking scheming smirk
* `gesture`: open chest raise point shrug fist palm wave show_hands salute
* `act` actions: salute bow shock laugh think cheer nervous point show_hands guilty stomp smirk wave touch cower
* `to`: a character name, or a number (0-1) for a place on screen
* After you change a text line: delete its `audio/line_XX.mp3` (or use `overwrite=True` in notebook 02) and render again.
* Background music: put a file at `music/music.mp3`; it is mixed in quietly.

To add new backgrounds, add a function in `engine/art.py` (see `make_garden`) or drop your own
1280x720 PNG into `assets/` named `bg_<name>.png` and use `"bg": "<name>"` in a scene.

## 5. Tips and problems

* **Bangla letters look broken in captions:** Pillow needs the *raqm* text engine. Linux: `sudo apt install libraqm0 libfribidi0`;
  macOS: `brew install fribidi`. Then reinstall Pillow (`pip install --force-reinstall pillow`).
* **Captions show boxes for commas:** the Bangla font has no comma glyph; `engine/text.py` falls back to a Latin font.
  If none is found, add a font path to `LATIN_FONT_CANDIDATES` at the top of that file.
* **Voices sound alike:** edge-tts has only two Bangla male voices. Change `rate` and `pitch` per character in `story.json`,
  or use a different TTS service later - any audio file named `audio/line_XX.mp3` works.
* **Better quality / longer videos:** change `fps` in `story.json`, or `crf` in `engine/render.py` (lower = sharper).
