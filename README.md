# 🚀 My AI/ML Journey

Welcome to my AI/ML learning journey! 🤖

I am a backend software engineer with 6+ years of experience, mainly working
with PHP, Laravel, JavaScript, Node.js, and system architecture.

Now I am starting a new journey into **Artificial Intelligence and Machine
Learning**.

My goal is not only to learn AI/ML theory, but to understand the fundamentals
and build real-world projects from scratch.

## 🛠️ My Learning Approach

I want to learn by **understanding → practicing → building**.

Instead of only watching courses, I will:

1. Learn the fundamentals
2. Practice with small problems
3. Implement algorithms
4. Work with real datasets
5. Build ML models
6. Build real-world AI projects
7. Document what I learn
8. Improve my projects continuously
